隱私權政策

生效日期：2026-10-18｜最後更新：2026-10-27

CalcTW 台灣試算（以下稱「本站」，網址 https://calctw.com/）重視您的隱私。本政策說明您使用本站時，哪些資訊會被蒐集、如何使用，以及您可以如何管理。本站由 CalcTW 網站營運者維護，隱私相關問題可透過本頁電子郵件聯絡。

1. 計算資料不會上傳

您在本站各計算工具輸入的薪資、貸款金額、利率、消費金額等數值，全部只在您的瀏覽器內運算，本站不會將這些數值傳送到伺服器，也不會儲存。匯出的 CSV 檔案直接由您的瀏覽器產生並下載到您的裝置。

上述說明限於本站計算程式：手動輸入的數值不由計算程式送出。載入廣告與流量統計時，第三方服務仍會收到連線資訊，例如網路連線所需的 IP 位址及瀏覽器送出的請求資訊。請勿把敏感數值放進網址參數或分享連結；網址本身屬於連線資訊，與表單內的本機運算不同。

2. 本站蒐集的資訊

  • 網站主機紀錄：本站以 GitHub Pages 託管，GitHub 可能為了安全與維運，記錄訪客的 IP 位址等技術資訊，詳見 GitHub 隱私權聲明。
  • 來信聯絡：若您以電子郵件聯絡營運者，會收到您的電子郵件地址、來信內容及您主動附上的檔案，用於回覆、重現問題與處理更正或委託需求。請先遮蔽不必要的個資。來信仍經電子郵件服務傳送與保存，不屬於只在瀏覽器內運算的資料。
  • Cookie 與類似技術：Google 廣告可能使用 Cookie，詳見第 3 節；流量統計另見第 4 節。

3. Google AdSense 與第三方廣告

本站公開頁載入 Google AdSense 廣告程式，以支應網站營運成本。關於廣告：

  • Google 等第三方廠商會使用 Cookie，根據使用者先前造訪本站或其他網站的紀錄來放送廣告。
  • Google 使用廣告 Cookie，讓 Google 及其合作夥伴能依據使用者造訪本站和（或）網際網路上其他網站的情形，向使用者放送合適的廣告。
  • 您可以前往 Google 的廣告設定（https://adssettings.google.com/），選擇停用個人化廣告；也可以造訪 www.aboutads.info，停用第三方廠商用於個人化廣告的 Cookie。
  • Google 如何使用合作夥伴網站的資訊，請參閱 Google 如何使用合作夥伴網站或應用程式的資訊，以及 Google 廣告相關說明。

4. 流量分析

本站使用 Cloudflare Web Analytics 統計瀏覽量。頁面載入 Cloudflare 的 beacon 指令碼以提供流量統計，用於了解網站使用情形與改善內容；這涉及瀏覽器與第三方服務的連線，不能將「計算輸入不由本站上傳」理解為瀏覽器沒有對外連線。詳情請見 Cloudflare 隱私權政策。

5. 外部連結

點擊外部來源或 LINE 聯絡連結後，您會前往第三方服務，其資料處理適用該服務的政策；外部連結與本站計算輸入的處理方式不同。

6. 管理 Cookie

您可以在瀏覽器設定中封鎖或刪除 Cookie。封鎖 Cookie 不影響本站計算工具的功能，但您看到的廣告可能較不相關。

7. 兒童隱私

本站不以 13 歲以下兒童為對象，也不會刻意蒐集兒童的個人資料。

8. 政策修訂

本站可能視需要修訂本政策，修訂後會更新本頁「最後更新」日期。
